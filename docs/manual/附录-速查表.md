# 附录 · 速查表

## A. REST API 常用端点（完整清单见 `/api-docs`）

### 领域推理（默认本体）

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| POST | `/api/domains/current/capabilities/query` | `{kind: capability_match\|orchestrate, params: {task}}` | 领域查询（R1–R4 的只读部分），纯读、可安全重试，附推导链 |
| POST | `/api/domains/current/capabilities/apply` | `{kind: assign, params: {task, agent}, persist?}` | 领域变更（如分配），会改图；`persist=true` 落盘，不保证幂等 |
| POST | `/api/domains/current/entities` | `{payload, persist?}`（字段形状看 `GET /api/domains/current/entities/schema`） | 按领域 schema 新建实体 |
| POST | `/api/domains/current/explain` | — | 最近一次查询的推导链（中文，模板填槽） |
| POST | `/api/domains/current/consistency` | — | 一致性 / 合规冲突全量检查 |
| GET | `/api/domains/current/ontology` | — | 本体结构（图谱渲染数据） |
| GET | `/api/domains/current/guide` | — | 使用视角说明：`profile`（声明）/ `runtime`（实测）/ `reconcile`（对账）/ `examples`（`safe` 由框架判定）；当前领域页唯一数据源 |

> `guide` 的响应字段与 `guide.json` 槽位表见[扩展新领域 · guide.json 字段表](../../guide/08-扩展新领域.md#guidejson-字段表第-5-步)。

### 通用查询（任意本体）

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| POST | `/api/query` | `{sparql}` | SPARQL SELECT，结果 IRI 自动转短名 |
| POST | `/api/individuals` | `{class_name}` | 指定类（含子类）的个体列表 |
| POST | `/api/classes` | — | 全部类层次（name/label/parent） |
| POST | `/api/types` | `{individual}` | 个体推理后的全部类型 |
| POST | `/api/property` | `{subject, property}` | 主体-属性取值列表 |
| POST | `/api/infer` | — | 重新推理，返回三元组/个体统计与 `breakdown` |
| POST | `/api/domains/current/cq/locate` | `{cq, conclusion_fields?}` | CQ 题干 → 本体承载条目（只读，不调模型） |

### 运维 / 本体管理

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| POST | `/api/ontology/load` | 文件 | 加载本体（切换为「导入的本体」只读领域） |
| POST | `/api/ontology/reload` | — | 热重载（原子替换，失败保留旧状态） |
| GET | `/api/ontology/status` | — | 本体状态（hash/dirty/changelog/counts） |
| GET | `/api/ontology/materialized` | — | 物化后本体 |

| GET | `/api/ontology/proof` | `?s=&p=&o=` | 单条三元组的结构化推导依据（asserted / derived / unproven；不存在的三元组返回 unproven，不报错） |
| GET | `/api/ontology/export` | — | 导出 |
| DELETE | `/api/domains/current/ontology/individual/{name}` | `?persist&cascade` | 删除个体（cascade 清理反向引用） |

| POST | `/api/domains/current/ontology/import` | `{individuals, persist}` | 批量导入（事务） |
| GET | `/api/ontology/edit-model` | — | 结构化编辑模型 JSON |
| POST | `/api/ontology/save` | `{model, filename, mode: new\|overwrite}` | 保存编辑模型并重推理 |
| GET | `/api/ontology/download` | `?name=` | 下载已保存 OWL（白名单防穿越） |
| GET | `/api/health` | — | 健康检查 |
| GET | `/` | — | Demo 页面（图谱工作台） |

## B. CLI 命令速查

### query.py（推理与查询，HTTP 优先 / `--local` 回退）

| 命令 | 说明 |
|---|---|
| `capability_match --task X` | R1/R2 能力匹配（附推导链） |
| `orchestrate --task X` | 复合任务拆解 + 依赖拓扑 + 逐环节匹配 |
| `assign --task X --agent A` | 分配 + R4 合规冲突检测 |
| `classify --name X [--capabilities --constraints --risk]` | 新增任务个体并分类 |
| `consistency` | 全量一致性 / 合规检查 |
| `explain` | 最近一次推导链 |
| `ontology` | 本体结构 |
| `query-sparql --sparql "…"` | SPARQL SELECT |
| `individuals --class X` | 类的个体 |
| `classes` | 类层次 |
| `types --individual X` | 个体推理类型 |
| `property --subject X --property P` | 属性取值 |
| `infer` | 重新推理统计 |

通道：`--http` 强制 / `--local` 强制 / `DOUBAO_API_BASE` 覆盖地址。

## C. MCP 工具清单（31 个：领域业务 9 + 建模/质量 7 + 引擎通用 15）

### 通用工具（任意本体）

| 工具 | 说明 |
|---|---|
| `query_sparql(sparql)` | SPARQL SELECT（IRI 转短名） |
| `individuals(class_name)` | 指定类（含子类）的个体列表 |
| `classes()` | 全部类层次 |
| `types_of(individual)` | 个体推理后的全部类型 |
| `property_values(subject, property_name)` | 主体-属性取值列表 |
| `infer()` | 重新推理，三元组/个体统计 |
| `explain_proof(subject, predicate, object)` | 结构化证明导出（asserted/derived/unproven） |
| `predefined_queries()` / `run_predefined_query(name, params)` | 受控预定义查询（需语义白名单） |
| `active_facts(property, at?)` | 时序事实（validFrom/validTo 半开区间） |
| `guard_status()` | 调用护栏状态（预算/循环/缓存/审计） |
| `pipeline_gate(ttl, abox?, gates?)` | 管线质量门禁 G1–G4 fail-fast 过闸 |
| `run_rules(max_iterations?, dry_run?, rules?)` | SHACL 规则执行（CONSTRUCT 派生三元组） |
| `list_rules(rules?)` | SHACL 规则清单（只解析不执行） |
| `merge_check(rdf_content, format?)` | 合并冲突预检（三类扫描 + 处置建议） |
